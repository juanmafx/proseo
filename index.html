About this page

This page is generated from a validated JSON catalog. Every value is escaped at render time, and the same repository ships an auditor that checks the published HTML for SEO metadata, microdata integrity, and a security baseline.

  • Nested schema.org microdata: WebPage, ItemList, Product, and Brand
  • Canonical URL, description, and Open Graph metadata
  • No JavaScript, no third-party requests, and a restrictive Content Security Policy

Originally created in 2016, modernized in 2026.
